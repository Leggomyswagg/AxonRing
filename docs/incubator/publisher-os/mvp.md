# AI Ebook Production Pipeline v1.0

## Product goal

Turn a manuscript into a professionally prepared ebook production package through a controlled AI workflow.

## Required inputs

1. Book title
2. Chapter files
3. Brand guidelines
4. Target audience

## Required outputs

1. Edited chapter
2. SEO metadata
3. Design instructions
4. Marketing assets
5. Publishing checklist

## Workflow

Intake -> validate -> extract chapters -> edit -> QA -> SEO -> design instructions -> marketing -> publishing checklist -> package outputs.

## Quality gates

- Preserve author intent and factual claims unless explicitly instructed to change them.
- Never silently invent citations, statistics, testimonials, or customer evidence.
- Flag factual claims that require verification.
- Keep brand terminology consistent.
- Return structured output for every stage.
- Record pipeline status and errors.

## MVP non-goals

- Direct marketplace publishing
- Billing
- Multi-tenant enterprise administration
- Autonomous financial or legal decisions

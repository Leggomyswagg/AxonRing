# Luxury hero and NFC landing page

The homepage has a responsive, semantic hero with a single H1, a clear NFC product definition and an early-access CTA. The focused landing page is `/nfc-smart-ring/`, with its own canonical URL, title, description, visible product questions and matching FAQ JSON-LD. The sitemap lists the actual static pages, replacing obsolete query-string catalogue entries.

Both pages share `public/styles/site.css`, `public/styles/brand-media.css`, `public/scripts/brand.js` and `public/scripts/site.js`. The landing page is a static HTML document under `public/nfc-smart-ring/`, copied into the production output by Vite. It does not require a second framework, hydration bundle, database migration or a server render per visit.

## Content and conversion

- Hero and repeated landing CTAs open the existing Founding Member form, preserving the consent checkbox and existing event names. CTA events include the page path and placement, so conversion by entry page can be measured.
- Confirmations appear only after successful requests. Failed submissions can be retried. Shared browser state falls back to memory when storage is blocked, and modal navigation supports keyboard focus and Escape.
- Homepage sizing copy describes guidance and confirmed launch details rather than promising unverified kit shipments, sizes, exchange windows or warranties. The current NFC ring does not promise bank-card terminal payments, health measurements or GPS.
- Search metadata includes canonical and social tags, Organization/WebSite/WebPage information and FAQ questions that are actually visible on each page. No invented ratings, testimonials, stock or sale offers are added. Search ranking, rich-result eligibility and conversion improvements are not guaranteed by this markup.

## Media

The owner supplied the on-hand photograph, gold wordmark and six-second city film. Three new reference-based editorial design studies were generated for the hero, lifestyle scene and macro detail. The generated originals remain in the workspace; the website ships optimized WebP derivatives.

The hero has 480/768/1024-pixel variants, a responsive preload, explicit dimensions and high fetch priority. Its largest WebP is about 93 KB. Supporting generated photos have 480/960/1536-pixel variants and lazy loading. The gallery also retains the supplied photographs and an optional archive of earlier campaign artwork.

The film has visible controls, a poster, captions, muted initial playback and `preload="none"`; it does not autoplay or download with the initial hero. All design imagery is presented as campaign imagery/design studies rather than evidence of manufactured stock.

## Verification

Run `npm run build`, `npm run lint`, syntax checks for the shared scripts and a check of all local asset references. Browser verification covered the homepage and landing page at 1440, 390 and 320 pixels, including blocked browser storage, the first-screen CTA, no horizontal overflow, menu behavior, modal focus/Escape, a failed signup followed by successful retry, visible FAQ/JSON-LD agreement and video playback. Provider/event requests were intercepted; no real signup, customer email, payment or supplier order was generated by those checks.

Desktop/mobile screenshots and detailed verification output are in the workspace portfolio folder `axonring-brand-media`. Production verification must separately check both live URLs and the deployed asset responses after publication.
